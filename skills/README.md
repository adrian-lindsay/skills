# Skills

This directory contains modular AI skills.

Each skill is self-contained in its own folder and includes at minimum a `SKILL.md` (or `skill.md`) with the core logic. Larger skills add:
- `references/` (rubrics, source lists, lookup tables)
- `scripts/` (helper scripts the skill can run)
- `examples/` (sample inputs and outputs)

## Skills

| Skill | What it does |
|-------|--------------|
| `last-30-days` | Monthly scan of public signal for emerging, well-timed, easy-to-ship micro-business ideas ($250–500/mo). Ranked shortlist with evidence and a 7-day validation test. |
| `style-deconstruction` | Reverse-engineer the structural, psychological, and linguistic style of any text sample into a replication blueprint. |
